## Default Permission

Allows the download center frontend package to manage download tasks.

#### This default permission set includes the following:

- `allow-execute`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`download-center:allow-execute`

</td>
<td>

Enables the execute command without any pre-configured scope.

</td>
</tr>

<tr>
<td>

`download-center:deny-execute`

</td>
<td>

Denies the execute command without any pre-configured scope.

</td>
</tr>
</table>
